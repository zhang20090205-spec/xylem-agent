# Xylem agent

This repository contains the full local hackathon workspace for Xylem agent, excluding local tooling folders and private credentials.

Primary app code:

- `Hedron_Frontend/` - React + Vite frontend.
- `Hedron/` - Hedera agent backend and TypeScript examples.
- `output/` - demo screenshots and generated presentation artifacts that are safe to publish.

Private `.env` files, API keys, wallet/private keys, dependencies, build output, local tunnel tools, and `.omx` are intentionally not committed.
